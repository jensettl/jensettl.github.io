This Markdown cheat sheet provides a quick overview of all the Markdown syntax elements. 

> 🗒️ This Cheat Sheet does not cover every edge case, just the basic I used to look up regularly.


| Element           | Markdown Syntax |
| -----------       | :-----------: |
| Headings          | # H1 <br> ## H2 <br> ### H3 <br> #### H4 <br> ##### H5 <br> ###### H6 |
| **Bold Text**     | \**Text** | 
| *Italic*          | \*Text\* |
| Blockquote        | > Text |
| Ordered List      | 1. First <br> 2. Second <br> 3. Third |
| Unordered List    |    - First <br> - Second <br> - Third |
| Code Line         | \`Code` |
| Code Block        | \`\`\` <br> Multiple Lines of Code <br> \`\`\` |
| Horizontal Rule   |   --- |
| Link              | [Text] (URL) | 
| Image             | ! [Text] (URL) |
