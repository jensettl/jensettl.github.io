> Langflow is a Low-code AI builder for agentic and RAG applications. It is a powerful tool to build and deploy AI agents and MCP servers. It supports all major LLMs, vector databases and a growing library of AI tools.


💡 Check out the Langflow Website to test it for yourself [here](https://www.langflow.org/) .

To explore the capabilities of Langflow, I created a workflow that generates a static website based on a pdf resume file. The workflow extracts relevant information from the resume and uses AI to generate HTML code for a simple, clean website that showcases the candidate's skills, experience, and projects.
